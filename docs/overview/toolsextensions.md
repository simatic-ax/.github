# AX Tools, Code Extensions

## Purpose

Here you will find a collection of community-driven tools, extensions, and improvements designed to support you in working the way that suits you best. Ranging from simple UI enhancements to powerful additions for the product toolchain. Ideally, contributions leverage the apax-contributed commands feature to align with standard package interactions, ensuring a streamlined and consistent overall AX experience.

These tools and extensions can be used for:

- advance your engineering experience
- customize your SIMATIC AX Code usability
- extend the product tool-chain
